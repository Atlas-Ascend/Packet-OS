# 09 — Agent Roles and Handoffs

JANUS authorizes and prioritizes. Atlas Mind interprets. Packet OS formalizes. CrownGrid routes. Workforce Spine assigns/executes. Domain agents perform. SECA verifies. ProofGrid receipts. Thoth/MAAT remember and reconcile.

Every handoff records sender, receiver, packet state, capability, payload version, timestamp, and expected return contract.

Agents do not inherit broader permissions merely by receiving a packet.
