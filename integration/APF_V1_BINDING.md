# Packet OS ↔ Atlas Prompt Fabric v1

APF lives under JANUS PRIME and compiles operator intent into Packet OS work contracts.

`operator -> JANUS/APF -> context compiler -> macro expansion -> governance validation -> packet compiler -> Packet OS -> Workforce Spine -> executor -> verification -> ProofGrid -> Thoth`

Packet OS does not interpret vague operator prose as authorization. It accepts the bounded APF packet contract. Failed packets emit a resume contract so successful upstream gates are preserved.

## Verification boundary
This binding defines the interface. Runtime integration is VERIFIED only when a correlated APF command produces Packet OS packets, executor results, verification evidence and a ProofGrid receipt using the same correlation/packet identifiers.
